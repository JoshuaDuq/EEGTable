# EEGTable logo

Three smooth signal traces resolve into aligned feature-table cells. The mark
represents the project's signal-to-table workflow.

## Assets

- `eegtable-logo.svg`: primary horizontal logo, transparent background.
- `eegtable-logo.png`: primary logo at 1072 × 256 pixels, transparent background.
- `eegtable-logo-dark.svg` and `.png`: logo for dark backgrounds.
- `eegtable-logo-monochrome.svg`: single-color logo for figures and print.
- `preview.png`: light, dark, monochrome, and small-size examples.
- `github-social-preview.png`: 1280 × 640 image for repository and documentation links.
- `../../docs/_static/logo-light.svg` and `logo-dark.svg`: standalone marks.
- `../../docs/_static/favicon.svg`: standalone mark with automatic theme colors.

Prefer SVG for publications and slides. All wordmark lettering is outlined;
the assets require no fonts or external resources. The lettering uses Noto Sans
Regular. Leave at least one feature-cell width of clear space around the mark.
Use the standalone mark at 16 pixels or larger.

The colors match the documentation: green `#08745c`, mint `#8dd9bd`, charcoal
`#202b33`, and light text `#e5e9ec`.

The existing theme integration follows
[Furo's light and dark logo documentation](https://pradyunsg.me/furo/customisation/logo/).
